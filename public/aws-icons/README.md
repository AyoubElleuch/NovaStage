# Official AWS architecture icons

These SVGs are unmodified assets from AWS's July 31, 2026 architecture icon package.

Source: https://aws.amazon.com/architecture/icons/

Archive: https://d1.awsstatic.com/onedam/marketing-channels/website/public/shared/architecture-icon-release/Icon-package_07312026.5846e92413caa21490223536cc97f1269e44fa92.zip

Copyright Amazon Web Services, Inc. or its affiliates. AWS permits these assets for architecture diagrams; see the source page for usage guidance. No affiliation or endorsement is implied.

Coverage: all 303 distinct Architecture-Service SVG names in this package, plus the official AWS Cloud group icon. Duplicate service icons appearing in multiple categories are deduplicated. This is architecture-symbol coverage, not a promise that every AWS product, sub-resource, regional offering, or discontinued service is available to deploy. The package also contains resource and group icons outside this service catalog.

The searchable metadata lives in `src/lib/canvas/aws-catalog.json`. Existing 42 service IDs and configurations are preserved. Future refreshes should preserve those IDs, audit new and renamed services, and compare all distinct service SVG names in the downloaded archive against the catalog before replacing assets.
