## Improvements delivered

1. Modern canvas onboarding card with gradient surfaces, distinct action icon containers, improved typography, and integrated shortcuts.
2. Navigator dark surfaces, readable results, emerald active states, filter pills, and shortcut badges harmonized with NovaStage tokens.
3. AWS search uses a text input, leaving a single custom clear button.
4. Category dropdown includes color indicators, keyboard navigation, outside dismissal, and an unclipped portal menu.
5. Canonical service alias indexing and exact-match ranking cover SES, SQS, SNS, EC2, ECS, EKS, RDS, IAM, S3, ALB/NLB, ECR, CDK, SSM, MSK, and further catalog abbreviations.
6. Canvas notifications stack at the top center of the canvas workspace, below the header and announcement area, with downward entry animations and reduced-motion support.
7. The bottom dock stays centered when details open; AI and notebook controls remain rendered.
8. Canvas keyboard interactions no longer draw a blue viewport outline.
9. SVG connections suppress rectangular focus outlines; node cards and comfortable port hit areas sit above wire hitboxes. AWS ports also support keyboard activation.
10. Milestone previews show up to five checkpoints, with remaining counts and shared dynamic dimensions for rendered cards, handles, fitting, and bounds.
11. Drawer status and boundary selectors use the accessible dropdown, preserving completion guards and including status/style indicators.
12. Groups drag from their headers; interiors remain pass-through. Layering distinguishes region/VPC/inner/selected groups, with different border styles and inset nested headers.
13. Clicking the broad wire hit area opens the label editor. Connection types now include HTTP/RPC, Queue/PubSub, Storage mount, and Security/IAM alongside the four existing types, supported by the editor, renderer, server, AI reconciliation, and migration.
14. Beta v1.1.1 metadata and a four-bullet October 14 release entry are complete.

The remaining native selector in the admin subscriptions table was also converted, so no native `<select>` elements remain in `src`.
