# Beta v1.1.4 — Bring your own AI to the canvas

Users can connect Codex or Claude Code to an individual canvas using a personal, expiring MCP credential. Their selected model generates workflows, AWS architectures, or combined full-stack diagrams without calling NovaStage's Gemini pipeline or consuming its AI quota. The existing built-in assistant remains available from its own tab.

The in-app assistant provides client setup commands, a prompt queue, connection activity, draft review, and revocation. External assistants can inspect the canvas, search the AWS catalog, read queued prompts, and propose diagrams. Users review generated tasks, services, configuration, groups, and connections before appending the diagram. Existing content is preserved. The connection must be installed in the user's client and the assistant must be prompted; browser setup does not silently start a local model.

Strict schema limits and catalog/reference validation guard the proposal and acceptance boundaries. Draft acceptance uses one PostgreSQL transaction for every node, checkpoint, parent group, edge, and status change. Duplicate acceptance and removed/banned members are rejected, active generation blocks acceptance, and stale layouts are rebased under a project row lock. A failed write rolls back completely. The shared graph validator also now breaks cycles introduced while reconnecting isolated milestones, improving built-in generation too.

The shared release metadata, package manifest, and lockfile identify Beta v1.1.4, dated October 26, 2026. The Updates tab has four release bullets and preserves prior history.

## Deployment

Apply `supabase/migrations/023_canvas_mcp.sql` after existing migrations before deploying this release. Existing Supabase service-role configuration is required; no additional AI API key is needed for MCP. See [canvas-mcp.md](../canvas-mcp.md) for the client setup, access model, and deployment details.

Connections use bearer tokens and Streamable HTTP. OAuth-only client installation flows are outside this release. Users must run the copied client setup and prompt their assistant to process queued requests. Diagrams are additive; direct overwrites and deletions through external assistants are intentionally unavailable.
