# Beta v1.1.3 — View-only sharing and mobile canvas improvements

Target: `dev` → `master`. This document supplies the PR description; no PR is created automatically.

## Description

Project owners can share an opaque, revocable canvas link without inviting someone to the project. Anonymous visitors can pan, zoom, search and inspect the same canvas cards, while project names, member lists, claim holders and author identities stay out of the public payload. The viewer exposes no mutation actions or private canvas API calls. Link management is owner-only, independent of project invites, and disabling a link prevents new visits.

The phone canvas now starts in pan mode, keeps the project title readable, provides larger controls and a compact tools menu, and opens details after creating content. Keyboard-aware panels, safer card swipes, selection focus, responsive AWS search, a clearer empty state and fitting AI results improve navigation and editing. Independent canvas queries load together, verified auth data is reused only within a server render, and workspace routes no longer wait behind the homepage intro.

Beta v1.1.3 is the current release throughout the landing page, login/signup, dashboard and subscription surfaces through the shared release constant. Package and lockfile versions match; earlier release history is preserved.

## Release notes

- Canvas sharing: Send a revocable, view-only link. Visitors can navigate and open canvas details without seeing the project name or members.
- Faster mobile loading: Load canvas data in parallel and enter the workspace without the homepage loading intro.
- Phone layout: Clearer project header, larger touch controls, a compact tools menu, and panels that stay usable above the keyboard.
- Touch navigation: Pan over cards without moving them, pinch to zoom, focus a selected item, and open details immediately when adding content.

## Deployment

Apply `supabase/migrations/022_canvas_sharing.sql` to the target Supabase project before enabling sharing in this release. Production schema and hosting have not been changed by this work. Public links disclose canvas content, including resource configuration and notes on canvas nodes; the share dialog explains this before enabling a link. Private browser notebook entries are not part of the shared canvas.

Links show canvas state when opened or reloaded. Disabling stops new visits; it cannot recall content someone already viewed or saved. Anonymous/public routes are marked no-store, noindex and no-referrer. Existing project membership checks continue to protect all editing endpoints.
